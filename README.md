# 📱 Emprestai

Aplicativo Android para gerenciamento de empréstimos de itens, com persistência de dados em nuvem utilizando Firebase.

## 🚀 Tecnologias

* Java / Kotlin
* Android SDK
* Firebase (Firestore / Realtime Database)
* Material Design

## 🔥 Funcionalidades

* Cadastro de usuários
* Registro de empréstimos
* Controle de devoluções
* Armazenamento em nuvem (Firebase)
* Atualização em tempo real dos dados

## 🧠 Sobre o projeto

Projeto desenvolvido inicialmente em grupo e posteriormente será evoluído individualmente, com foco em melhorias de arquitetura, integração com serviços em nuvem, experiência do usuário e segurança.

## 🔧 Melhorias implementadas

* Integração com Firebase
* Refatoração de código
* Melhor organização de camadas
* Melhorias na interface

## ☁️ Firebase

O projeto utiliza Firebase para:

* Armazenamento de dados
* Sincronização em tempo real
* Escalabilidade sem necessidade de backend próprio
