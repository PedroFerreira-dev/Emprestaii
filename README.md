# 📦 Emprestai

Sistema de gerenciamento de empréstimos de itens.

## 🚀 Tecnologias

* Java
* Spring Boot
* Banco de dados (ex: MySQL)
* Android (se aplicável)

## 🎯 Funcionalidades

* Cadastro de usuários
* Controle de empréstimos
* Histórico de operações

## 🧠 Objetivo

Projeto desenvolvido inicialmente em grupo, posteriormente evoluído individualmente com melhorias e novas funcionalidades.

## 🔧 Melhorias implementadas

* Refatoração de código
* Novas features
* Melhor organização de arquitetura

## ▶️ Como rodar

```bash
git clone https://github.com/seu-usuario/Emprestaii.git
```
